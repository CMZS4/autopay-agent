# AutoPay Agent 🤖

An agentic payment assistant that understands natural language commands and executes stablecoin transfers on Tempo automatically.

## What it does
- Sends stablecoin payments via natural language commands
- Built on Tempo testnet (Chain ID: 42431)
- Uses AlphaUSD stablecoin transfers

## Tech Stack
- Node.js + ethers.js
- Tempo blockchain (payments-optimized L1)
- Claude AI (natural language processing)

## Setup
1. Clone the repo
2. `npm install`
3. Create `.env` file with `PRIVATE_KEY` and `WALLET_ADDRESS`
4. `node transfer.js`
